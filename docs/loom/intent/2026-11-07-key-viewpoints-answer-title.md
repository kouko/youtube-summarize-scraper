# Intent: 主要觀點需回答標題提問/主題

## 問題背景
現行文章體摘要的 `## 主要觀點` 僅要求「濃縮講者核心立場與關鍵判斷」。許多影片標題為疑問句或承諾式（如「何去何從」、「為什麼」、「怎麼選」、「避坑指南」），若摘要只講立場而不給標題承諾的結論，讀者得到的只是背景而非答案。

## 驗收條件
1. `## 主要觀點`（或英/日對應標題）**同時**做到兩件事：濃縮核心立場，並**直接回答或解釋影片標題中的問題／承諾／主題**（相加，非二選一）
2. 標題為疑問句時，開頭段直接給出答案與結論；標題為承諾式/主題陳述時，說明該主題最後的結論或解釋
3. 既有 11 項驗收全部保持通過（格式、C 模式、動態圖數、無元敘述等）
4. 三語言同步生效

## 驗證結果（2026-11-07，測試影片 w8GM1mghKJc）
- 第四輪：標題回答規則生效（主要觀點直接給出「何去何從」的結論）；元敘述 4 處違規（haiku 換詞繞過禁令）
- 第五輪：對照表策略，違規降至 3 處
- 第六輪：改為**正向主詞白名單**（每句主詞只能是市場/指數/個股/板塊/政策/數據/事件/機構/具體人物），違規降至 1 處
- 第七輪（同規則重跑）：**0 違規**，全部驗收通過（含「面對『何去何從』的問題，答案是：…」直答格式）
- 結論：白名單策略收斂；殘留屬 haiku 服從性隨機漏網（最壞約 1 處/輪），決定不換模型、不以代碼後處理修改輸出文字（用戶決定：維護性優先）
- 修訂僅涉及 prompt 檔案（zh-Hant/en/ja 三語言同步），無代碼變更

## 判斷邏輯（供 LLM 參考）
- 標題含 `？`、`怎麼`、`為什麼`、`何去何從`、`該不該`、`值不值得`、`怎麼辦`、`What`、`Why`、`How`、`Should`、`Worth` 等 → **開頭段直接給出答案/結論**
- 標題為承諾式/主題陳述（如「推薦」「避坑」「指南」「教學」「How-to」「某事件分析」） → **說明該主題最後的結論或解釋**
- 標題為單純名詞/主題陳述（如「台積電財報分析」、「美股早盤回顧」） → 仍要解釋標題所指主題的結論，同時濃縮核心立場（相加，非二選一）
