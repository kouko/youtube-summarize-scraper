status: confirmed 2026-11-01
publication: automatic — authorized 2026-11-01 by kouko## Problem
在 TUI 裡選好設定檔後，使用者沒有辦法把設定檔的路徑帶出程式：要複製路徑只能手動打字或另外開終端機；要在 Finder 找到設定檔必須自己記住路徑再去一層層找。畫面上明明顯示著路徑，卻沒有任何方式把它帶出 TUI，來回切換視窗浪費時間。

## Proposed outcome
使用者可以從 TUI 把目前選取的設定檔完整路徑複製到系統剪貼簿，也可以在 Finder 開啟該設定檔所在的資料夾。動作的結果（成功或失敗）會以可見訊息回報，不會被默默忽略。

## Acceptance
1. 已選取設定檔且設定卡有焦點時，按下複製鍵後，系統剪貼簿的內容等於該設定檔的完整路徑（可讀取剪貼簿驗證）。
2. 已選取設定檔且設定卡有焦點時，按下開啟鍵後，會對該設定檔所在資料夾執行 macOS 的 Finder 顯示指令，且指令成功返回（可實際執行並確認返回成功）。
3. 尚未選取設定檔時，按下複製鍵或開啟鍵不會執行任何剪貼簿或 Finder 動作，畫面上會出現一行說明「尚未選取設定檔」的訊息。
4. 每次按下複製鍵或開啟鍵後，畫面上會出現一行訊息說明該動作的結果（成功或失敗原因）。
5. 設定卡有焦點時，畫面下方的提示列會顯示這兩個新按鍵。
6. 原有的按鍵行為（Enter 開啟選單、c 切換檢視、r/s/q、Tab、方向鍵）不受影響。

## Constraints
- 開啟資料夾功能限 macOS（使用者指定以系統的 Finder 顯示指令達成）；非 macOS 平台上該按鍵不動作或顯示不支援訊息。
- 新按鍵不得與現有按鍵衝突。
- 只複製路徑本身，不得複製設定檔內容（依 PRINCIPLES：永不洩漏秘密）。
- 既有按鍵行為不變。

## Value case
beneficiary: 在 TUI 中管理設定檔、需要把路徑帶出程式或到 Finder 查看設定檔的使用者（即使用者本人）。
urgency: 低——純便利性改善，現有流程可繞過（手動複製、另開終端機）。
existing alternative: 手動輸入/複製路徑、另開 Finder 視窗自行導覽。
displaced work: 無，不取代任何現有功能。
GO — 低成本便利功能，無重大風險，與「無人值守持續運作」原則無衝突。

## Out of scope
- 用預設 app 開啟設定檔內容（使用者已明確只選「開啟所在資料夾」）。
- 複製設定檔內容或任何其他文字到剪貼簿。
- 非 macOS 平台的開啟資料夾功能。
- 剪貼簿以外的其他複製目標（如內部暫存區）。
