## 你交代不能動的部分

- `q` / `ctrl+c` 的離開行為（含執行中的雙重確認）：實測未變。執行中按一次 `q` 會出現「再按 q 離開、按其他鍵取消」的提示，按其他鍵即取消；連按兩次 `q`、或連按兩次 `ctrl+c` 都會停止 pipeline 並離開程式；沒在執行時按一次 `q` 就直接離開。
- `batch.random_order` 與批次處理邏輯：這次完全沒有動到，變更只涉及畫面的按鍵與提示。

## 對你既有的資料做了什麼

沒有。這次變更只影響介面上的按鍵與提示，沒有讀寫你原本的設定檔、輸出檔或任何既有資料。

## 我替你決定了什麼

- **停止時不跳確認對話框** — 我選了按 `s` 就直接停止，因為停止的內部邏輯本來就存在，確認框只會多一層操作。之後要改成先確認，得另外加對話框。
- **`[s] Stop` 只在執行中出現** — 我選了停止時不顯示這個提示，因為那時按了也沒作用。之後要改成一直顯示，只要改提示列即可。
- **停止後不顯示「停止中…」之類的過渡字樣** — 我選了狀態直接切成 Stopped，因為停止是立即生效的。之後要加過渡字樣，得再多一個中間狀態。
- 這次沒有被退回、需要說明取捨的重大問題。
